02 / Highlights

Architecture · System Design

What's inside.

01

Zero-Window Workflow

No slow windows to launch, no file picker dialogs to navigate. Simply drag any file in Windows Explorer or on your Desktop, hold Shift, and drop it on the radial menu.

02

Non-Destructive Guarantee

Your original files are never overwritten or deleted. Squeeze always saves compressed output side-by-side as name_compressed.ext with automatic conflict numbering.

03

Multi-Format Intelligence

Lossy and lossless compression across JPEG, WebP, PNG (PNGQuant-style palette quantizing), HEIC, TIFF, multi-page PDFs, MP4/MKV video, and MP3/FLAC audio with FFmpeg.

04

Target Size Snapping

Need an image under 500 KB or 1 MB for an email portal? Drop on that exact wedge. Squeeze lowers quality first, shrinking pixel dimensions only if strictly necessary.

05

100% Offline & Private

Zero cloud uploads, zero external telemetry, zero tracking. Everything runs locally on your machine's CPU/GPU. Your sensitive documents and photos remain entirely yours.

06

Featherweight Native

Built with PySide6 and direct Win32 hooks. Uses under 40 MB of RAM, sleeps at near-zero CPU in the system tray, and triggers instantly when needed.

Run from Source

Prefer running directly with Python? Squeeze requires Python 3.10+ and 4 lightweight packages.

POWERSHELL / BASH 
# 1. Clone repository
git clone https://github.com/Araveenp/Squeeze.git
cd Squeeze

# 2. Install dependencies
py -m pip install -r requirements.txt

# 3. Launch background tray app
pythonw app.py
